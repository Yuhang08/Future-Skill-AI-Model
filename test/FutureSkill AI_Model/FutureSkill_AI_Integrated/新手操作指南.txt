FutureSkill AI 合并版 — PyCharm 新手启动步骤
===============================================

重要：这份代码已经把原本的 RIASEC + Career Recommendation 和新 Reskilling 模块放进同一个网站。
千万不要把两份旧的 app.py 同时运行。先备份旧项目。

【第一步：解压】
下载 FutureSkill_AI_Integrated_Complete.zip，右键 → 全部解压缩。

【第二步：打开 PyCharm】
PyCharm → File（文件）→ Open（打开）→ 选择解压后的 FutureSkill_AI_Integrated 文件夹。
如果询问是否新窗口打开，选择 New Window，保留原本项目。

【第三步：安装所需依赖】
在 PyCharm 底部打开 Terminal（终端），输入：

python -m pip install -r requirements.txt

等安装结束。

【第四步：关闭旧服务器】
若你之前已经在 PyCharm 运行旧 app.py，点击旧 Run 窗口中的红色停止按钮。
因为旧服务器可能正在占用 8000 端口。

【第五步：启动合并版】
在新项目的 Terminal 中输入：

python -m uvicorn app:app --host 127.0.0.1 --port 8000

请注意，不是运行旧的 app.py，也不是同时运行多个服务器。

【第六步：浏览器测试】
原本职业测评：  http://127.0.0.1:8000/
新学习路线：    http://127.0.0.1:8000/reskilling

先在首页完成 42 道测评，查看职业结果，在每张职业卡片按
"Explore reskilling options" 就会进入同一个网站的学习路线。

【第七步：学习路线操作】
填写职业和技能自评 → 每周学多少小时 → 可用的星期几 → Generate my pathway。
之后可以勾选任务、看 XP 树、上传照片、调整学习时间表。

【提醒】
- 原来的职业推荐数据库包含 923 条职业记录；学习路线目前只有 5 种示例职业技能模板。
  不在这五种中的职业不会被假装已有准确的技能需求模型。
- 原来的 6 项技能自评和职业兴趣分数，不等于具体职业技能的掌握程度，所以新问卷仍需要单独评分。
- 以前另一个独立 Reskilling 网站保存的 SQLite 进度不会自动搬到新合并版。
- 这是本地演示网站。若要公开部署，需要补齐注册登录、HTTPS、图片处理与隐私控制。

【如何确认没有错误】
在 PyCharm Terminal 运行：
python -m unittest discover -s tests -v

如显示 Ran 3 tests / OK，主要后端流程通过测试。

【如果出现错误】
- ModuleNotFoundError: 请确认 Terminal 使用的 Python interpreter，并再次运行 pip install。
- Error 8000 already in use: 先停止旧服务器再运行。
- 页面显示旧版：确认运行的是新项目的 app:app，按 Ctrl+Shift+R 强制刷新。
- 新页面没出现：试着直接打开 http://127.0.0.1:8000/reskilling。
