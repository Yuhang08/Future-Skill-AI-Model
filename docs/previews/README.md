## SDG circular layout

这一节保留圆形方案用于对比。当前 5／4／4／4 方案见下一节。

17 个 SDG 节点按 360° / 17（约 21.18°）等角度排列，从 12 点方向的 Goal 1 开始顺时针分布，职业位于中心。Goal 17 留在同一外圈，连接线在圆形边缘外停止。

只有与当前职业有已审核潜在关联的 Goal 圆环运行激光；大面板、搜索框和侧栏保持静态边框。手机端采用圆形节点网格，保留清晰的点击区域。

## SDG 5-4-4-4 layout

宽屏将 Goal 1–5 放在上方，6–9 放在右侧，10–13 从右向左放在下方，14–17 从下向上放在左侧。顶部向内收一列、底部四张居中，中心职业保留圆形雷达样式。

矩形卡片与连接线留出独立通道；Goal 17 不再占据内圈，也不挡住通往 Goal 1 的路径。激光只绕与当前职业有已审核关联的 Goal 卡片运行。较窄地图和手机使用自适应网格。
